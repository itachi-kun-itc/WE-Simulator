# 震度推定モデルの改訂

一次資料確認日: 2026-10-28。実装は `web/earthquake-model.js`、接続処理は `web/app.js`。

## 今回の結論

Mと震度は一対一には対応しない。同じMでも、距離、震源の深さ、断層面、地震タイプ、地点の地盤で震度が変わる。地震のエネルギーの式だけから地点の震度を決めることはできない。[気象庁の説明](https://www.jma.go.jp/jma/kishou/know/faq/faq27.html)

独自のM一次式を、最大速度を介する経験的予測に置き換えた。気象庁の震源要素による手法を基本にしつつ、通常モードは点震源距離、断層モードは断層までの幾何学的距離を使う。手元のJ-SHIS地盤データに合わせて基盤速度を補正する。気象庁の現行システムの再現や、波形から計測震度を算出する処理ではない。

## 旧実装で確認した点

| 対象 | 旧処理 | 改訂 |
| --- | --- | --- |
| Mから震度 | `1.43M − 2.12log10(R+20) − 0.0042R − 0.95` を中心とする独自式 | 司・翠川(1999)の最大速度→地盤増幅→翠川ほか(1999)の震度換算 |
| 規模 | Mの種類を区別しない | 入力をMj/Mwで明示し、必要な場合だけ換算 |
| 巨大地震 | `0.32 max(M−7.4,0)^2` を震度から減算 | 断層距離モデルは振幅のMwを8.3で頭打ち。通常の点震源参考計算は入力Mwを使う |
| 地盤 | ARVの対数補正にAVSの軟らかさと深部地盤の独自補正を加算 | ARVを速度に一度掛ける。AVSはARV欠損時のみ |
| 通常モードの距離 | 海域名などで係数を変えて震央距離を減じ、その後に深さを合成 | 入力した点震源までの3次元距離。速報向け球面からの距離へ置き換えない |
| 矩形断層 | 代表線上の小震源からの距離。幅・傾斜角が最終震度に効かない | 有限の傾斜矩形面までの最短距離 |
| その他の断層 | 小震源の配置間隔で近距離値が変わる | 代表線の連続線分までの距離。小震源は時間演出に使用 |
| 震度階級 | 途中で小数2桁へ丸める箇所がある | 観測点の予測値と時刻ごとの計算値は丸めずに階級へ変換 |

## 入力と計算順

以下の `log` は常用対数。距離・深さはkm、AVSはm/s、PGVはcm/s。

### 1. マグニチュード

通常モードの初期値はMj、断層モードはMw。入力欄から変更できる。

```text
Mw = Mj − 0.171  （Mjを選んだ場合のみ）
Mw = 入力値       （Mwを選んだ場合）
```

これは気象庁の緊急地震速報で採用されている経験的な換算で、すべての個別地震のMjとMwがこの差になるという意味ではない。既知のMwを入力できる場合はMwを選ぶ。[気象庁 技術的参考資料、13頁](https://www.jma.go.jp/jma/kishou/know/jishin/eew/katsuyou/reference.pdf)

Mの種類と地震タイプは保存・共有シナリオにも含める。旧シナリオは通常モードMj／地殻内、矩形・活断層モードMw／地殻内、海溝型プリセットMw／プレート間として解釈する。保存済みのパラメータにも改訂後の計算法を適用するため、過去版と同じ予測結果は保証しない。

### 2. 通常モードの点震源距離

```text
R = sqrt(震央距離² + H²)
X = max(R, 3)
```

通常モードでは震源点の位置と深さを入力するため、その点までの距離を使う。断層の大きさや傾斜を再現する計算ではなく、断層距離式へ点震源距離を入力した参考計算である。気象庁資料にも発表内容に応じた点震源距離の利用が記されている。[同資料、12〜13頁](https://www.jma.go.jp/jma/kishou/know/jishin/eew/katsuyou/reference.pdf)

初回改訂では、断層形状不明時の速報に使われる保守的な球面近似 `L=10^(0.5Mw−1.85), X=max(R−L/2,3)` を通常モードへ一律適用した。しかしMw9ではL/2が約223kmとなり、浅い震源の周囲約220kmまでが同じX=3kmになる。震源近傍の距離減衰が消えて地盤差が支配する平坦域を作っていたため、通常モードから撤去した。震度そのものを震央中心の同心円へ固定したり、震央付近が必ず最大になる補正を加えたりはしない。

点震源のM9は実際の巨大地震の破壊域全体の再現ではない。広い震源域のシナリオは断層モードで形状を指定する。旧来の海域名による距離補正も使わない。

### 3. 明示的な断層形状

手動矩形では指定緯度経度を断層中央、入力深さを断層中央深さとする。走向に沿う座標u、右手側の走向直交座標v、傾斜角δ、幅Wについて、面上の下降傾斜座標qを次のように求める。

```text
qmin = −min(W/2, H/sinδ)     （地表より上に断層を作らない）
qmax = W/2
q = clamp(v cosδ − H sinδ, qmin, qmax)
u* = clamp(u, 断層の走向方向下端, 断層の走向方向上端)
X = sqrt((u−u*)² + (v−q cosδ)² + (H+q sinδ)²)
```

最終的に距離減衰式へ入力するXは3km以上とする。幅は断層面内の幅で、地表への水平投影幅ではない。上端の地表クリップと傾斜による水平投影は地図の矩形にも反映する。垂直断層は表示のためだけに10m幅とし、振幅計算には使わない。地理座標から局所平面への換算は近似で、広域曲面・標高・地球内部の速度構造を解くものではない。

「中央から片側へ破壊」の設定では既存仕様どおり破壊する半分の領域のみを計算に使う。海溝型・主要活断層のプリセットは、既存の代表線の連続線分からの距離と代表深さを合成する。公的モデルの詳細な3次元断層面、SMGA、すべり量、放射特性を読んで計算しているわけではない。

### 4. Vs600m/sの基準基盤上の最大速度

```text
Mw_amp = Mw              （通常の点震源参考計算）
Mw_amp = min(Mw, 8.3)    （断層距離モデル）
log PGV600 = 0.58 Mw_amp + 0.0038 H + d − 1.29
             − log(X + 0.0028 × 10^(0.5 Mw_amp)) − 0.002 X

d =  0.00  地殻内
    −0.02  プレート間
    +0.12  プレート内
```

基本式は気象庁の技術資料、タイプ係数は[防災科研の解説](https://www.j-map.bosai.go.jp/j-map/result/tn_257/html/html/2-4-1.html)による。海／陸や深さだけでプレートの種類を自動推定しない。タイプを変更した場合はその選択値で計算する。

Mw8.3での振幅頭打ちは、J-SHISの断層最短距離による地震動ハザード評価で採られた追加のモデル選択で、気象庁資料の基本式そのものにはない。[防災科研研究資料399号、2.6.2](https://dil-opac.bosai.go.jp/publication/nied_tech_note/pdf/n399_1.pdf)。本アプリでもこの上限は断層距離モデルのみに適用する。通常の点震源参考計算に一律適用してM8.3とM9を同値にしてはいけない。ただし、上限を外すことはM9での精度保証ではなく、Mw8.2超は原式の観測データ範囲を超える外挿として記録する。[建築研究所の原式解説](https://iisee.kenken.go.jp/eqflow/reference/1_13.htm)

巨大地震では、断層最短距離か等価震源距離かによって見かけの振幅飽和も異なることが原著者らにより報告されている。ここで通常モードを等価震源距離式へ変更したわけではなく、距離定義と係数を混用しない。[司ほか(2016)](https://www.jstage.jst.go.jp/article/jaee/16/1/16_1_96/_article/-char/ja/)

### 5. 基盤条件を揃えて地盤増幅

```text
PGV400 = 1.31 × PGV600
PGVsurface = ARV400 × PGV400
```

手元のJ-SHISのARVはVs400m/sの工学的基盤から地表への速度増幅率。[J-SHISの使い方](https://jmapweb6v.bosai.go.jp/usage)、[基盤速度600→400の補正](https://www.j-shis.bosai.go.jp/j-map/result/tn_283/html/html/5.html)。気象庁のARV700に使う0.90倍をARV400に掛けるのは基準の混同になる。関数自体はARV600・ARV700にも対応するが、本アプリの地盤接続はARV400を使用する。

ARVが欠損し、AVS30だけがある場合は松岡・翠川(1994)の速度増幅式の比から `ARV400=(400/AVS30)^0.66` を近似する。AVSは100〜1500m/sへ制限し、ARVがある場合にはAVSを重ね掛けしない。双方欠損時はARV400=1の工学的基盤を仮定する。地盤なしを一般的な土の平均と解釈してはいけない。

`maxDepthM` は最深の地層境界値で、特定のVs層の上面深度ではない。任意の盆地補正には使わない。AVSや深部地盤を用いた既存の時間演出は、最終最大震度の計算から分離している。

### 6. PGVから震度へ

```text
I = 2.68 + 1.72 log(PGVsurface)
```

翠川ほか(1999)による関係で、気象庁資料では震度4〜7を対象とし、換算のばらつきを±0.21とする。地盤増幅が2倍なら、他条件が同じときの増分は `1.72 log(2) ≈ 0.518`。速度の倍率を震度の加算値としてそのまま使わない。[気象庁 技術的参考資料、14頁](https://www.jma.go.jp/jma/kishou/know/jishin/eew/katsuyou/reference.pdf)

内部の生の推定値は保持し、画面用の数値だけ0〜7へ制限する。震度7は「6.5以上」の開いた階級で、実際の計測震度が7.0で上限になるという意味ではない。階級境界は0.5、1.5、2.5、3.5、4.5、5.0、5.5、6.0、6.5。途中で四捨五入して境界を跨がせない。[気象庁 階級表](https://www.jma.go.jp/jma/kishou/know/jishin/kyoshin/kaisetsu/calc_sindo.html)

波形からの正式な計測震度では、3成分加速度のフィルター処理と累積0.3秒の振幅を使う。同じ資料の `I=2log(a)+0.94` に、PGAやPGVを直接代入してはいけない。本改訂では波形を合成していない。

## 分布図の意味

観測点、現在地、区域内観測点の予測最大値は同じ地点モデルを使う。細分区域の一色の塗りは区域内観測点の代表最大値であり、区域のどこでも同じ震度という意味ではない。観測点がない区域は最近傍形状等による概算で、地盤メッシュ全セルの最大値を網羅していない。

時刻ごとの色は従来のP波／S波の立ち上がり演出を通す。これは波形解析によるリアルタイム震度ではない。到達時間・円表示は既存の一定速度による簡略演出のままで、JMA2001走時表を用いる気象庁の到達予想は再現していない。今回の検証対象は最終最大震度とその分布である。

過去地震のプリセットは実際の観測震度を優先する。プリセット再生が観測と一致することをもって予測式の精度検証とはしない。

## 適用範囲・採用しなかったもの

- 原式は主に浅い地震から作られた経験式。小規模地震、遠距離、震度4未満は参考外挿とする。関数の結果に範囲外の理由を付け、入力欄でも参考値であることを表示する。
- 原式の観測データのMは5.8〜8.2。Mw8.2超も外挿として明示する。通常モードでMを大きくしたときに振幅が増加することと、現実のM9地震の複雑な分布を再現できることは別である。
- 深さ150km超は計算不可として扱い、震度0との混同を避けて「推定対象外」と表示し、新規の予測シミュレーションは開始できない。深発地震の観測プリセットは再生可能。気象庁資料15頁の制限に合わせたもので、異常震域を任意の係数で代用しない。
- 気象庁は2025-07-24に地盤増幅度の一部を250mの全国震度増分由来へ変更した。本アプリの地盤はJ-SHISデータの1km集約で、観測点補正も未導入。したがって「現行気象庁と同じ」とは説明しない。[気象庁 技術情報653号](https://www.data.jma.go.jp/suishin/jyouhou/pdf/653.pdf)
- [森川・藤原(2023)によるMF2013の適用解説](https://www.j-shis.bosai.go.jp/labs/mf2013/)も確認した。同モデルにはVs1400層上面深度、火山フロントからの距離、対象プレートに応じた補正等が必要。現在の`maxDepthM`をVs1400深度と見なして導入することはしない。
- 最終振幅は経験式の中心値。地震ごとのばらつき、破壊指向性、地盤非線形、建物応答を再現するものではない。学習用の任意震源シミュレーションであり、実地震の予報ではない。

## 検証

`npm run check:earthquake` は式の別計算値、ARV基準、Mj/Mw、単調性、階級境界、矩形距離、画面計算への接続、保存互換を確認する。

`npm run audit:earthquake` はM×断層距離の表と、能登半島地震の12観測点に対する診断比較を出力する。[数値監査結果](earthquake_model_audit.md)参照。これは強震地点だけの限定標本で、全国・複数地震での検証を代替しない。係数の再調整は行っていない。
